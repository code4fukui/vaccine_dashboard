# FUKUI Vaccine Dashboard (FUKUIワクチンダッシュボード)

> [!WARNING]
> 2023年4月19日をもって、このサービスは鯖江市を除くすべての市町で終了いたしました。

本プロジェクトは、福井県内の医療機関における新型コロナウイルスワクチンの予約空き状況を表示するダッシュボードです。オープンデータを集約し、住民向けに市町ごとのシンプルな表形式で提示します。

## デモ

*   **サービス終了のお知らせ:** [https://code4fukui.github.io/vaccine_dashboard/select.html](https://code4fukui.github.io/vaccine_dashboard/select.html) （旧・市町選択画面）
*   **ダッシュボード（鯖江市）:** [https://code4fukui.github.io/vaccine_dashboard/#%E9%AF%96%E6%B1%9F%E5%B8%82](https://code4fukui.github.io/vaccine_dashboard/#%E9%AF%96%E6%B1%9F%E5%B8%82)
*   **医療機関向けデータ入力:** [https://push.sabae.cc/#type=vaccine](https://push.sabae.cc/#type=vaccine)

## 主な特徴

*   **市町別表示:** 市町ごとに絞り込んで予約空き状況を表示します。
*   **Tabular Maps（カラム地図）ナビゲーション:** CSSベースの表を用いて福井県の市町を視覚的に配置し、簡単に選択できるようにしています。
*   **リアルタイムデータ:** PUSHオープンデータプラットフォームから最新の予約データを取得・処理します。
*   **2週間以内のフィルタリング:** 現在の日付から概ね2週間先までの空き状況のみを自動的に抽出し表示します。
*   **直接予約リンク:** 電話番号（`tel:`）またはURL（`http:`）のクリック可能なリンクを生成し、予約手続きを容易にします。

## 仕組み

このダッシュボードは、JavaScript ESモジュールを使用してクライアントサイドでデータを取得・処理する静的ウェブアプリケーションです。

1.  `fetchData.js` が `push.sabae.cc` 上の複数のオープンデータエンドポイントからデータを取得します。
2.  多くの市町のデータはメインのCSVファイルから取得され、福井市のデータは個別のJSONファイルから取得されます。
3.  スクリプトは予約日を直近2週間以内にフィルタリングし、データを統一された構造に整形した上で、電話番号とURLの情報を単一の予約リンクに統合します。
4.  処理されたデータは、選択された市町（URLハッシュ経由で渡される）に基づいて、`index.html` 上のHTMLテーブルに動的にレンダリングされます。

## データソース

ダッシュボードは以下のオープンデータエンドポイントからデータを集約しています。

*   **メインデータ（多くの市町）:** `https://push.sabae.cc/817.csv`
*   **福井市 - 基本情報:** `https://push.sabae.cc/876.json`
*   **福井市 - 空き状況:** `https://push.sabae.cc/877.json`

データには以下のフィールドが含まれます: `医療機関名`、`市町名`、`住所`、`空き状況`、および連絡先・予約情報。
